This communication thread will be used to provide transparency into buyback execution via OTC. We will update this post with links to any relevant dashboards and will post execution details monthly. As the program authorizes 50% of all revenue generated in 2026 to be used to buyback OP, the program will commence in February, using January’s monthly revenue.

Here’s how buyback execution timing will work via OTC.

  • First month of Buyback (February): ETH to OP conversion using the month of January’s revenue will be completed between T+25–35 from February 1.

  • After the first month, execution will happen at the same time each month during the same window.

  • After the completion of each monthly conversion to OP, this thread will be updated with details.

Our intent with this timeline is to minimize execution risk. If this timeline changes at any point, we’ll post updates here.

OTC execution is a temporary implementation until we transition execution fully onchain within the next ~6 months.
