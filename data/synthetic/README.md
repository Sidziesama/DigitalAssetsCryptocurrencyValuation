# Synthetic data

Nothing in this directory is evidence. Every file is generated by
`src/pipeline/survey_synthetic_responses.py` from a fixed seed, and exists so the
panel analysis can be exercised and its edge cases checked **before any real
response is read**.

`survey_panel_analysis.py` refuses to write into `data/processed/` when its input
path contains `synthetic`, and stamps `data_source: synthetic_fixture` on the
output, so a fixture result cannot be mistaken for a finding.

Scenarios cover the branches the frozen plan has to get right:

| Scenario | What it exercises |
|---|---|
| `consensus` | a rule adopted at 70 percent or more; also the duplicate-response exclusion |
| `leaning` | a unique plurality between 50 and 70 percent — unresolved, not validated |
| `tie` | an exact 50/50 split — must resolve to divided, never to leaning |
| `divided` | no option at 50 percent |
| `depends` | the condition-dependent option winning — adopts no value and cannot satisfy G1 |
| `sparse` | item-level denominators, and scorer pairs below the minimum overlap |
| `degenerate` | every scorer answering identically — both coefficients undefined, never imputed |

Regenerate with:

```bash
python -m src.pipeline.survey_synthetic_responses --scenario tie --n 12
python -m src.pipeline.survey_panel_analysis --responses data/synthetic/survey/synthetic_responses_tie_n12_seed20260914.csv
```
